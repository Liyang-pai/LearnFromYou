# 讲给我听 · Learn From You

**当前仓库的前端是开发调试界面**，用于验证 ASR 转写效果与 AI 学生试讲链路。它不是面向用户的正式产品界面；正式前端将另行设计和开发。

一个本地语音识别、云端 Student LLM 的试讲练习工具。教师讲授时，AI 学生只根据明确的前置知识和本次课堂内容形成认知，不会因为课题名称就默认知道答案。

> 当前版本主要在 **macOS Apple Silicon** 上验证。ASR 模型管理、下载和 CPU 识别面向 macOS / Windows x64，CI 覆盖两端。系统语音支持 macOS `say` 和 Windows 本地 System.Speech；Windows 优先选择已安装的中文语音。

## 下载者需要配置什么

| 项目 | 是否必须 | 说明 |
| --- | --- | --- |
| Python 3.11–3.13 | 必须 | 推荐标准版 Python 3.13。Windows x64 缺少兼容版本时启动脚本自动安装；macOS 需自行安装。虚拟环境由脚本自动创建。 |
| 本地 ASR 模型 | 必须 | GitHub 不包含任何模型文件。启动网页后，在「ASR 模型」页面下载并选择；支持安装多个。详情见 `asr/README.md`。 |
| DeepSeek 或兼容 LLM API 密钥 | 必须 | 将密钥写入本地 `.env`，不会上传或提交到 GitHub。 |
| Chrome 麦克风权限 | 试讲时必须 | 选择真实麦克风，不要选择 `Background Music (Virtual)` 等无教师语音的虚拟设备。 |
| 耳机 | 建议 | 降低学生语音播报被重新识别为教师语音的概率。 |

## 从零安装

普通使用者下载项目 ZIP 并解压后，按系统选择启动文件即可，无需手动创建虚拟环境或运行 pip：

- **Windows x64**：双击 `启动试讲.bat`。脚本优先复用可用的项目环境和 Python；未找到兼容版本时，自动下载并安装官网标准版 **Python 3.13.16 x64**。安装前核对官网 SHA-256 和 Python Software Foundation 有效数字签名，按当前用户安装到 `%LOCALAPPDATA%\LearnFromYou\Python313`，不修改 PATH、不安装 Python 启动器、不自动重启电脑。
- **macOS Apple Silicon / Intel**：先从 [Python 3.13 官网发布页](https://www.python.org/downloads/release/python-31316/) 选择 macOS installer 安装标准版 Python 3.13，再双击 `启动试讲.command`。macOS 脚本不自动安装 Python。

首次启动会在项目内创建 `.venv` 并安装 `requirements.txt` 中的依赖，需要联网，请保持启动窗口开启。后续会检查版本约束、依赖一致性和模块加载；环境完整时不访问安装源、不自动升级依赖。依赖缺失或损坏时会安装或修复；虚拟环境不可用时先保留为 `.venv.backup-时间戳`，再重建。不要将另一台电脑或另一种系统的 `.venv` 一起分发。

Windows 下载 Python 时显示真实百分比、已下载大小和平均速度；服务器未提供文件大小时显示已下载大小和动态等待提示。安装 Python、创建虚拟环境、检查及安装依赖时显示动态状态与已等待时间，命令输出和错误仍会保留。重定向输出或 CI 中，Python 环境配置使用普通日志，避免动画刷屏。

Python 安装包下载不限制总耗时；等待服务器响应或连续 180 秒未收到新数据时才会超时。只要下载持续推进，即使超过三分钟也会继续。

Windows 安装器来自 [Python 3.13.16 官方发布页](https://www.python.org/downloads/release/python-31316/)，版本与 SHA-256 固定在脚本中，不会在每次启动时追踪最新版本。安装日志位于 `%LOCALAPPDATA%\LearnFromYou\downloads`。下载、校验、安装或依赖检查失败时，脚本显示错误并停止；处理网络或目录权限问题后重新双击即可。若安装器提示需要重启，请手动重启后再启动。也可以自行安装兼容版本，再重新双击。

**启动环境自动配置不包含 API 密钥和 ASR 模型。** 首次使用仍需把 `.env.example` 复制为 `.env` 并填写密钥，然后在网页「ASR 模型」页面下载、选择模型。已有 `.env`、模型和课堂日志不会被脚本覆盖。

开发者也可以手动安装：

```sh
git clone https://github.com/Liyang-pai/LearnFromYou.git
cd LearnFromYou
python3 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

随后编辑 `.env`，至少填入：

```dotenv
DEEPSEEK_API_KEY=你的密钥
```

默认使用 DeepSeek：`LLM_BASE_URL=https://api.deepseek.com`、`LLM_MODEL=deepseek-chat`。也可以填写兼容 OpenAI Chat Completions 接口的地址与模型名。旧版字段 `Deepseek_API` 仍可用，但新安装请使用 `DEEPSEEK_API_KEY`。

随后启动服务，在网页「ASR 模型」页面下载并选择模型。首次配置无需预先安装模型；选择成功后返回课堂。推荐优先尝试 Paraformer 中文完整版，轻量选择为标准 SenseVoice Small INT8；另有 Whisper Small / Turbo INT8。详见 [ASR 模型管理](asr/README.md)。

仅测试语音转文字时，可直接在模型页面的「ASR 转文字调试」点击「开始录音测试」，无需填写主题或配置 LLM 密钥。停顿后显示逐段转写、音频时长、识别耗时和实时系数；结束录音会处理尾段并释放模型，随后可切换模型再次测试。结果可清空或导出 JSON，音频不写入文件，也不调用 LLM / TTS。

Windows PowerShell 使用 `.venv\Scripts\python.exe` 替换下面的 `./.venv/bin/python`，复制环境示例可运行 `Copy-Item .env.example .env`。模型不需要单独安装 GPU 或 CUDA 环境。

## 启动

```sh
./.venv/bin/python run.py
```

Windows 可双击 `启动试讲.bat`，macOS 可双击 `启动试讲.command`；两端都会在服务就绪后自动打开试讲页。使用系统默认浏览器，建议将 Chrome 设为默认浏览器；若未能自动打开，可使用终端显示的地址，默认为 **http://127.0.0.1:8765**。终端保持开启，按 Ctrl+C / Control-C 关闭服务。

端口已被其他程序占用时启动会失败，不会终止占用进程或打开其他服务。可关闭先前启动的本项目终端，或在 `.env` 中设置其他 `PORT` 后重新启动。仅准备环境而不启动服务时，开发者可运行 `python scripts/bootstrap.py --prepare-only`（使用兼容 Python）。

页面必须通过本机服务地址访问。直接打开 `frontend/index.html` 会跳转到默认地址 `http://127.0.0.1:8765/models`；若修改了 `PORT`，请使用相应端口的 HTTP 地址。若提示无法连接，请先启动服务。

更新代码后，需要在原终端按 Control-C，再重新启动服务并刷新网页。服务不会自动重新加载 Python 代码；只刷新网页可能出现新页面连接旧后端的情况。ASR 调试面板会检查后端是否支持调试接口，并在版本不匹配时提示重启。

1. 填写教学主题，点击“生成学生画像”，或直接手写画像。年级、学科可由 AI 判断；知识点可选填，已填写时保持原文。检查并编辑学生已有知识、理解基础和知识边界。创建前在「ASR 模型」下载并选择模型；点击“创建试讲”即确认当前画像。仅生成画像不需要 ASR。
2. “语音转文字审核”默认开启，可在创建前关闭，课堂中不可切换。开启时先准备本课术语表；准备完成后，点击“开启麦克风”，允许浏览器使用麦克风，并选择真实麦克风设备。建议戴耳机。
3. 自然讲授。转写按短段显示；教学内容聚合后，开启审核时先校正识别错误，再按顺序发送给学生模型。调试台保留原文、校正文本和审核耗时。
4. 可以直接问“你理解了吗”，或停顿让学生提出相关疑问。
5. “学生静音”完全禁止学生发言，但继续识别和学习；“语音播报”只控制声音。
6. 结束试讲会处理末尾转写，并保留学生状态。创建下一次试讲不继承前次知识。

调试时展开“用文字测试同一条学习链路”，输入教师讲授或问题。它使用同一学生引擎，发送时立即形成教学片段，不替代麦克风功能。文字输入不做审核，但会等待先前语音片段完成，保持讲授顺序。

### 学生画像

年级与学科默认“由 AI 判断”，支持自定义；学生水平默认普通水平，课型默认新课。教材版本在“更多设置”中选填。AI 可以推断合理的前置知识，需教师确认；待讲内容不自动视为已掌握。画像有内容时重新生成会询问是否覆盖，取消或生成失败均保留全部输入。生成中暂时锁定教学表单，避免重复提交。

学生画像为空或只有空白时，前后端都会拒绝创建，提示“请生成或填写学生设定，再创建试讲嗷~”。手写画像同样可以创建。画像在本次课堂中固定，课前准备调用从中逐字摘录明确已知的领域知识作为 `p` 来源；困难、未知与待讲内容不应提取。动态认知从版本 0 开始，随课堂更新。完整设置保存在课堂日志中，不作为跨课堂记忆。

接口、迁移规则与验证方式见 [学生画像接入说明](docs/student-profile.md)。

### 上传音频测试

试讲页和 ASR 模型页都可以选择音频文件，解析后会显示文件名与时长，点击“开始音频测试”即可重复使用同一份录音。支持 WAV、MP3、M4A，以浏览器能否解码为准；文件最大 700 MiB、最长 60 分钟。建议音频10分钟以内，长音频或大文件解码时会占用较多内存，可能导致页面卡顿或处理失败。解码失败可转换为 PCM WAV 或 MP3。文件只在浏览器内存中读取，后端接收采样数据，不保存音频文件，也不播放音频。

上传沿用麦克风的 VAD 分段和本机 ASR，采用快速处理，按后端逐帧确认控制发送速度。进度表示已处理的采样比例，到 100% 后仍需等待尾段识别。快速处理不会模拟录音中的课堂停顿时长，审核批次和学生回应时机可能与实时录音不同。

- **试讲页**：先创建试讲，并手动暂停麦克风、等待处理完毕。上传内容与麦克风同等地进入本次课堂记录、可选文字审核和学生处理链路。音频识别完成后，课堂状态继续显示审核和学生处理进度。
- **ASR 模型页**：只做本机识别，逐段显示转写和耗时，可导出结果；不调用 LLM，不生成课堂日志。结束试讲后才能进行独立 ASR 测试。
- **停止上传**：不再发送剩余内容，但处理已经接收的音频并保留结果。试讲页不会撤销已进入课堂的内容。结束试讲会先停止上传，再完成课堂收尾。

上传期间不能混入麦克风或文字输入。完成后可以再次测试所选文件，麦克风需要手动开启。连接断开不会自动重传，已有结果保留；使用旧后端时上传按钮会禁用，需要重启服务并刷新页面。

审核只校正明显的同音词、术语和断句错误，保留口语、重复、教师的知识错误及无法确定的表达；模型仍可能误改，请结合两份文本检查。术语表只供校正器使用，不计入学生知识。审核复用现有云端模型，会增加请求和等待时间；失败时提示并回退原文，课堂继续处理。默认术语准备上限 30 秒、每个语义片段审核上限 15 秒，包含格式修复重试，可通过 `ASR_REVIEW_GLOSSARY_TIMEOUT` 和 `ASR_REVIEW_TIMEOUT` 调整。

## 本地与云端边界

麦克风音频只在本机处理，不上传，也不默认写入录音文件。画像生成会将教学设置交给已配置的云端模型；课堂调用接收确认后的画像、课堂转写、明确前置知识、学生状态及必要的历史上下文。模型密钥只由后端读取，不进入网页或日志。

开启审核时，校正器另行接收主题、准备讲授的知识点、术语表、当前片段和最近 8 条已完成审核或直通的教师来源，不接收学生认知或学生发言。学生模型只接收实际采用的课堂文本，不接收术语表和原文审计字段。

`.env` 兼容原有 `Deepseek_API`，也支持 `DEEPSEEK_API_KEY`。可选设置见 `.env.example`。默认 API 地址为 `https://api.deepseek.com`、模型为 `deepseek-chat`。启动后修改配置需要重启服务。

## 模块

- `asr/catalog.py`、`manager.py`：固定模型清单、下载校验、本地选择与安装状态。
- `asr/recognizer.py`：SenseVoice / Paraformer / Whisper CPU 适配、采样率处理、Silero VAD。仅在试讲时加载，不使用云端 ASR。
- `asr/upload.py`、`frontend/audio-file.js`：上传协议校验与进度、浏览器文件解码和逐帧发送，复用原有音频处理能力。
- `backend/session.py`：音频、转写和认知更新的串行队列，会话与发言控制。
- `backend/student_profile.py`、`frontend/student-profile.js`：独立画像生成、教学设置回填、覆盖保护与创建校验。
- `backend/review.py`：可选转写审核、独立术语准备、总等待时限与失败回退。
- `backend/prompts.py`：课前与课堂 Prompt。教学材料作为数据，不作为系统指令。
- `backend/schemas.py`、`policy.py`：结构化状态、来源校验、提问生命周期与静音规则。
- `backend/llm.py`：兼容接口，可替换地址和模型；无效 JSON 最多修复一次。
- `backend/speech.py`、`windows_speech.py`：macOS / Windows 本机语音，支持停止播报。Windows 使用系统自带 Windows PowerShell，无需新增 Python 依赖。
- `frontend/`：本地网页、麦克风 AudioWorklet、调试面板。

状态只在本次会话维护；`logs/会话编号.jsonl` 保存调试事件，属于本地调试记录，不是跨课程长期记忆。可从网页导出同样的事件记录。日志包含讲授文本和模型输入输出，需要时可以自行清理。

## 分段与互动默认值

- VAD 静音 0.6 秒结束一个语音段；连续语音最长 12 秒切段。
- 教学分段停顿 3 秒提交；超过 300 字后停顿 1 秒；已有稳定文本最长等待 20 秒。
- 点名后约 1 秒停顿即可处理；其他情况至少停顿 5 秒才考虑主动提问。
- 模型耗时额外计入实际响应时间。状态按序提交，旧候选发言会在新输入到达后撤销。
- 同一个问题最多提问两次；合理解释后关闭。静音期间关闭的疑问不会在解除静音后补播。
- 模型格式或课堂关联错误最多自动修复一次，共用两次请求预算。若最终只是追问漏登记，则跳过异常追问，提交其他校验通过的学习记录并继续课堂；调试台会记录恢复原因。
- 网络失败、最终无效 JSON 或其他校验失败仍暂停认知队列并保留待处理文本；点击“重试这一段”。结束时若仍有未处理内容，界面会明确列出。验证与边界见 [追问异常恢复](docs/question-recovery.md)。

## 测试

```sh
./.venv/bin/python -m pytest -q
./.venv/bin/python asr/transcribe.py /完整路径/录音.wav
```

启动服务后，执行真实 API 和录音数据链路测试（会使用少量 DeepSeek 配额，不会播放声音）：

```sh
./.venv/bin/python tests/live_smoke.py
```

单独检查真实模型的转写审核（会使用少量配额，不需要麦克风）：`./.venv/bin/python tests/live_review.py`。实际原文、校正结果、耗时及样例断言保存到 `logs/asr-review-quality.json`；这些有限样例不代表所有课堂内容都能正确校正。

`asr/transcribe.py /完整路径/录音.wav --model 模型ID` 支持选择已安装模型进行独立 WAV/FLAC 转写。默认测试使用模拟下载；真实模型测试在本地文件存在时运行。准确性比较工具与数据格式见 [ASR 说明](asr/README.md)，推荐标签尚未用真实课程录音验证。

上传自动化覆盖在 `tests/test_upload.py`，包含真实 VAD 的麦克风/文件分段对比（本地模型和样本存在时运行）。可在已提供 Playwright 的环境中运行 `node tests/upload_browser.cjs`，验证真实浏览器解码、本机 ASR、停止与输入互斥。`UPLOAD_TEST_URL` 指定本机服务地址，`CHROME_PATH` 可指定浏览器，`UPLOAD_EXTRA_FILES` 用分号分隔额外 MP3/M4A 样本。仅显式设置 `LIVE_CLASSROOM=1` 时才使用已配置的真实 LLM 验证课堂链路，会产生少量 API 用量；默认浏览器测试只使用本机 ASR。

整个 `asr/models/` 被 Git 忽略，小型 VAD 和本地配置也不会提交。CI 使用 `scripts/check_model_files.py` 拒绝任何被强行加入索引的模型目录文件。

## 已知边界

首版只允许一个活动试讲，主要面向本机的耳机演示。外放回声消除仅作为辅助，不保证复杂环境下学生语音不会被麦克风收回。识别是短段最终转写，不是逐字即时转写。

程序检查来源是否存在，无法仅凭引用编号证明一句话完全由课堂支持。Prompt 也不能让预训练模型真正忘记知识；需继续用未讲内容、错误但自洽的讲解和特殊术语做回归测试。

“课堂推断理解”（understood）根据课堂行为推断，不代表标准答案或永久掌握。本版不提供教师评分、多学生、视觉、长期记忆或账号系统。

认知结构版本为 `schema_version: 2`。`knowledge` 记录独立结论，`open_questions` 管理问题生命周期，`recent_events` 保留最近 20 条课堂事件；新增 `conflicts` 和 `pending_reviews` 管理矛盾与依赖复核。旧 `questions` 输入仍可读取，历史 `conflict` 不自动改成 `invalid`，原始日志不改写。

知识有五种状态：`understood`（课堂推断理解）、`tentative`（可补跳步或依赖未确认前提）、`unclear`（当前无法建立理解链条）、`conflict`（学生可识别的同条件矛盾）、`invalid`（明确撤回或纠正的旧知识）。冲突双方的矛盾部分暂停作确定前提；其他独立知识保留。例子、表格、类比等合理路径均可建立理解，不要求补齐原先的每个缺口。

每条知识记录依据、来源、适用条件和版本化依赖。画像摘录的 `p` 基础也可修订，当前状态优先于原始画像。同 ID 纠正保存已失效的旧版本，不同 ID 替代用 `supersedes` 将旧条目置为 `invalid`。依赖 `tentative` 的结论不能自动成为 `understood`；前提变化先在本轮复核，剩余目标触发额外模型调用，每批最多 16 条。待复核结论暂不作确定前提，失败可手动重试且不阻塞继续输入。

实施细节、验收边界及运行方式见 [五状态知识状态机](docs/五状态知识状态机.md) 和 [最终架构图](docs/状态机改进流程图/LearnFromYou-最终状态机架构.drawio)。离线专项测试：`./.venv/bin/python -m pytest -q tests/test_knowledge_machine.py tests/test_knowledge_review.py`；真实模型验收：`./.venv/bin/python tests/live_knowledge_machine.py --live`（八组固定案例，同一输出目录共享最多 48 次请求，含修复与失败）。浏览器展示检查：`node tests/knowledge_machine_browser.cjs`，需 Playwright，可设置 `CHROME_PATH`。

真实星星运算文字回放：后台加载最新代码且课堂空闲时运行 `.venv\Scripts\python.exe scripts/verify_cognition.py`。需自行提供原始日志 `logs/3e206b001729.jsonl`；脚本回放教学片段并检查未讲规则、未完整纠正、普通课堂回答及结束事件，会调用实际模型并消耗 API 额度，不重新验证原始音频的 ASR 效果。详细机制与验证边界见 [V1 认知状态改造说明](docs/V1认知状态改造说明.md)。


## Windows 语音播报

Windows 使用 System.Speech 的已安装语音，通过本机默认音频设备播放。可用 `TTS_VOICE` 指定语音名称；没有同名语音时优先选择已启用的中文语音，否则使用系统默认语音。无需配置语音 API 密钥。

播报文字通过标准输入传入，不拼接到 PowerShell 脚本中；播报进程不弹出窗口。主动停止或被教师打断视为正常中断，不报语音失败。声音来自运行后台的电脑。更新代码后需重启后台并刷新网页，在课堂勾选“语音播报”，同时检查电脑音量与输出设备。

## 教学报告增量分支

本分支从 main 增加独立教学报告。正常结束试讲后先释放课堂资源，再由后台自动分析。报告约250–350字，正文最多400字符：实际讲授概括、四维短评、一个优先发现与保留做法、一个具体改法、1–3分钟独立练习。理解相关判断融入现有评价；报告不展示统计、原文清单或证据编号，不包含独立课后理解测试。长课按顺序分段，失败可复用已成功阶段；刷新只读取，不重新调用模型。范围、API与验证见 [简明教学报告](docs/teaching-report-first.md)。
