## 尚未满足的质量验收与风险

1. 真实模型的第一人称自然度、忠实复述、错误讲授保留、题目答案暗示、引文语义支持和建议质量，仍需用户批准后的 API 评估。
2. 引文存在和来源关系校验不能完全证明结论语义正确；报告只是一种模拟教学反馈。
3. 教师实际提问次数在未标注语音时无法统计；有回应证据依赖 main 的 resolution_sources，不把缺记录等同教师从未回应。
4. 没有完整长课堂压力和真人麦克风→报告重跑；沿用 main 的 ASR 排空和约 100 秒学习收尾边界，音频排空仍没有统一总超时。
5. 60k 字符容量保护、60 秒阶段超时、有限输出 token 与修复次数会使某些课堂无法生成全部 AI 内容；确定性结算保留。
6. 没有自动迁移旧课堂 JSONL 为 V2 报告；没有自动日志保留清理、跨课程列表或账户系统。
