## 尚未解决的质量边界及建议

已复现的 P0 路径已修复，程序不再只凭答案正确或措辞不同给积极结论。但是逐项任务是否真的完成仍包含模型语义判断；引文有效、结构完整不能数学证明独立理解，也不能保证消除所有长尾误判。新版提示词仍需下一轮授权后的真实 DeepSeek 验收。

显式疑问关联采用保守的主题短语匹配。歧义片段不强行判为独立疑问，而显示无法统计、已关联数量和限制；没有承诺任意口语疑问都能识别。负面诊断的保守过滤可能漏掉合理但缺充分课堂证据的不足，不靠补齐推断凑评价。

学生语言修正主要是提示约束和安全的句式/术语转换，不是一次新的真实模型质量评估。仍需由队友检查自然度、课堂忠实性、推理语义及引用支持程度。

适合队友做下一轮受控本地体验。建议把本轮修复用于草稿 PR 评审，明确上述限制；新版真实模型验收通过后再考虑合并。本轮仅允许本地提交，不执行远程写入。
