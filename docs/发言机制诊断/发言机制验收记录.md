## 真实课堂轨迹

1. 缺少“折光”定义，学生第一次用 `question` 提问。
2. 教师仍未解释，学生第二次澄清；实际发出后次数为 2，疑问暂缓。
3. 普通继续讲授，模型主动沉默，未产生第三次追问。
4. 教师明确询问疑问，模型使用原问题 ID 的 `question` 并附例外申请；程序通过后发出，次数为 3，仍暂缓。
5. 教师检查声音，学生使用 `ack`，不重复请求解释。
6. 学生静音时教师再次邀请，记录邀请而不发言；解除静音后重新生成 `question` 与申请，实际发出后次数为 4。

## 复现

```sh
./.venv/bin/python -m pytest -q
node tests/question_release_browser.cjs
node tests/question_recovery_browser.cjs
node tests/mute_resume_browser.cjs
node tests/knowledge_machine_browser.cjs
./.venv/bin/python tests/live_question_release.py --live --output /tmp/lfy-question-release-live
```

浏览器需要 Playwright，可设置 `NODE_PATH`、`CHROME_PATH` 和 `LFY_TEST_PYTHON`。真实模型测试需要已配置的密钥及网络，调用配置好的外部模型服务；固定脚本只生成测试课堂，不读取历史日志。该脚本关闭 TTS，本机语音检查单独完成。

## 生效与边界

重启后台、刷新页面并新建课堂；确认页面运行版本与 `ready` / `llm_request` 一致。只刷新网页不能更新已加载的后端规则。

邀请语义由同一次模型判断；程序强制检查来源原文、时效、关联、计数与使用状态，不保证模型对所有自然语言的语义分类绝对正确。实际扬声器声音仍需用户在本机确认。
