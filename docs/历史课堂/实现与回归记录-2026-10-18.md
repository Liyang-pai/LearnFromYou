# 历史课堂实现与回归记录

## 功能

从 `feat：-Liyang-alpha对前端原型的修改` 的 `dcbef43` 创建 `codex/classroom-history`。

调试前端增加“历史课堂”，地址为 `/history`；详情地址为 `/history/{session_id}`。与课堂、ASR 模型共用页面，切换不销毁实时课堂容器。

列表仅展示主题、学段、学科和上课时间。详情展示当时确认的画像、按事件顺序排列的全部师生对话、教学报告及原始 JSONL 日志下载。每批读取 50 条对话，支持加载更早记录。老师正文采用审核文本，原始转写可以展开。未发出的候选不作为学生发言。

未正常结束的课堂仅供查看已保存记录，不支持恢复课堂或续讲。缺画像、无讲授、记录损坏分别提示，不调用模型补齐。

## 接口及存储

| 接口 | 行为 |
| --- | --- |
| `GET /api/history?offset=0&limit=20` | 倒序列表；`indexing` 表明旧日志正在后台整理 |
| `GET /api/history/{session_id}` | 画像、课堂概况、对话数量及报告生成条件 |
| `GET /api/history/{session_id}/dialogue?before=N` | 读取 N 之前最多 50 条对话；首次省略参数读取最后一批 |
| `GET /api/history/{session_id}/log` | 直接下载原始日志，不先把日志载入浏览器 |

派生缓存保存在 `logs/.history/`，包括版本、源文件大小和修改时间、摘要和分页对话。源日志不变时复用缓存；旧版本在重新整理后清理。后台最多同时整理两堂课，同一课堂共用任务。就绪、结束、关闭后安排更新，首次查看旧日志时按需补建。

报告沿用 `/api/teaching-report/{session_id}`：有报告直接显示、生成中轮询、首次缺失自动 POST；失败后仅手动重试。未正常结束、没有讲授内容或记录不完整时不自动生成。报告读取新增有界材料缓存，源文件或报告提示词变化时失效，避免每次轮询重扫原始日志。生成任务注册加锁，重复打开共用一个任务。

## 验证

- 完整离线套件：**454 passed，11 skipped**。跳过项为当前环境不满足的可选模型样本、Windows 专属检查等；没有将跳过项计为通过。
- 历史浏览器回归：列表字段、画像、132 条完整对话、原始转写、日志下载、分页、导航与刷新、报告缓存、失败手动重试，以及桌面和 390 px 窄屏。另以浏览器测试音源启动实际 AudioWorklet 采集和 WebSocket 发送，验证切换历史后音频帧持续增加、课堂连接不关闭。
- 现有浏览器回归：学生画像表单、课堂静音与恢复发言、教学报告，均通过。此处“恢复发言”为现有静音开关，不是恢复历史课堂。
- 页面错误及非预期 HTTP 错误：未发现。

## 真实 API 验收

独立服务端口 `8895`，独立数据目录 `/private/tmp/lfy-history-live-20261018`；核对运行代码来自指定 worktree。API 全程共用 14 次请求硬上限，自动修复和重试也计入。

实际完成惯性短课：2 段教师讲授、1 条真实学生回复；对话与原始日志逐条一致，历史画像与创建时一致，下载内容校验通过。正常结束后的报告生成成功。另用该日志的测试副本验证：

1. 打开历史自动补生成报告。
2. 注入一次请求发送前的失败，页面刷新不自动重试；点击重试后真实模型生成成功。
3. 生成中离开并重新打开仍复用任务；生成后刷新不增加调用。
4. 两个页面同时打开另一份缺报告的副本，仅产生一个真实报告请求。
5. 画像、完整对话、日志下载、报告内容及桌面和窄屏页面均可查看，无浏览器错误。

**实际 6 次模型请求**：课前准备 1、学生处理 2、报告 3。没有自动结构修复请求。故障注入发生在 HTTP 请求前，不产生付费请求，单独计为 1 次注入。

提供方返回用量合计：输入 27,366 tokens，输出 2,388 tokens，总计 **29,754 tokens**，其中输入缓存命中 20,224 tokens、未命中 7,142 tokens。未估算费用。

原始日志、报告、用量明细及截图留在独立测试目录，未提交 Git；API 密钥未写入测试材料。
