# 主动提问 Prompt 调整与验收

日期：2026-10-14（上海）。本轮起始范围为只调整提示词，不新增输出字段或修改程序门控。

## 已完成的提示词调整

- 新的关键理解障碍或冲突，应进入主动提问判断；“未被点名”不能单独成为沉默理由。
- 区分新的独立疑问、已有疑问覆盖、等待教师回应和教师明确稍后解释；同一缺口不按知识条目重复提问。
- 教师已针对疑问作答但关键缺口仍在，应在剩余一次澄清机会中继续询问；与教师尚未回答的等待区分。
- 同题两次上限及教师邀请例外保持原样；暂缓只限制对应疑问，不压住其他独立疑问。
- 提问简短具体，topic 写明对象；note 说明实际提问或等待理由。静音恢复沿用同样判断。

## 验证事实

完整离线回归：336 项通过、8 项跳过。真实模型使用新编造的卡片课堂，不重发用户的历史课堂。

真实模型已验证：完整讲解保持安静；新缺失定义主动提问；补齐定义后不重复；新冲突主动提问；等待回答时不重复；教师回应但未消除关键矛盾时追加一次澄清；两次后暂缓且不继续主动重复。

复现脚本：`tests/live_active_questions.py`。原始输出、实际候选和最终回复分别记录，避免把“模型想提问”误当作“实际已发出”。
