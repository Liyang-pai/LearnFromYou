# 初中课堂学生反应回归测试使用说明

本目录提供 5 个可重复使用的 AI 学生课堂案例。材料用于后续真实模型测试，当前没有执行结果。测试教师对学生的讲授、提问与补讲效果，不修改产品代码，也不替代真人学生学习效果研究。

## 2. 三条测试路径

每课使用相同画像和设置，按下图执行。路径 A 与 B 必须是两个独立的新课堂；C 是 B 的延续，不能重新创建课堂或重置学生状态。

```text
新课堂 1 → A 正常教学（约 10—15 分钟）→ 结束并保存
新课堂 2 → B 跳步教学（约 10—15 分钟）→ 保存阶段记录
                                           ↓ 不结束课堂
                           C 补讲恢复（另约 10—15 分钟）→ 结束并保存
```

每课完整执行约 30—45 分钟，共 10 个独立课堂、15 段路径。时间包含教师讲授、学生处理与回答、思考和记录；是人工试讲的建议预算，不是系统响应时限。各稿按约 1—2 分钟一轮安排。文字输入可能更快，应记录实际用时，不靠重复提问或强制空等凑时长。

若只复测某条路径：A 可单独执行；B 可单独执行并结束；C 必须先完整重放 B。若 B 中学生已自行补出缺失依据，继续 C，但标记“跳步未形成缺口”，不能宣称补讲修复了困难。

## 3. 创建课堂和输入规则

1. 按各稿设置主题、年级、学科、普通水平、新课，教材版本留空。将“固定学生画像”代码块完整粘入画像栏，不再生成画像；将规定的“知识点”填入对应栏，不填答案或判定区。保存实际设置与画像副本。
2. 建议第一轮使用“用文字测试同一条学习链路”，每个编号单独发送，等待处理完毕再进行下一轮。不要整篇粘贴，不把多轮合成一次输入。A 与 B 使用同一输入方式和相同设置。
3. 语音照读时只读各轮引用块里的教师话术；公式按通常数学或物理读法朗读。分别记录识别原文、审核后实际进入课堂的文本；审核开启状态在创建前确定，同组对照保持一致。判定以学生实际收到的文本为依据。
4. 测试时学生静音关闭；语音播报可关闭，但同组保持一致。明确提问轮等待有效回应；纯讲授轮只等处理完成，学生可以保持沉默，也可以提出相关问题。
5. 明确提问处理完毕后仍无回应，先记录等待时长和界面状态。建议观察至 60 秒；仍无回应就记为“发言失败/链路待复核”，不要直接断言知识不理解。可继续下一轮，必要时停止该路径并保留记录。60 秒只是本套人工观察窗口。
6. 不临时提示、表扬某个答案、解释判定答案或追问额外知识。学生主动提问时先记录，后续按稿补讲；若必须现场回答，该次标记“偏离脚本”，保留原话，不能和严格脚本运行混算。
7. B 的最后一轮处理完毕后记录状态，立即在同一课堂进入 C。阶段记录只保存证据，不向学生发送。整次结束后保存会话编号、导出的事件记录或 `logs/会话编号.jsonl` 的实际位置。

## 4. 怎样判定

每轮分开记录三项，不能只看“有没有答出数字”。

| 维度 | 通过的证据 | 失败或待复核的证据 |
| --- | --- | --- |
| 理解表现 | 能解释依据、识别缺口，或有依据地推导；补讲后能解决新题 | 错误推理、照搬结论而不能迁移；技术中断则待复核 |
| 知识依据 | 使用画像明确已有知识、实际教师讲授，或可还原的推导 | 无依据调用本课未教结论；把问题、学生自己的话伪装成教师讲授 |
| 发言表现 | 明确提问得到相关回应，允许承认不会、提出澄清 | 问题已处理但没有回应、答非所问；纯讲授轮沉默不算失败 |

- **不以“不会”作为唯一合格反应。** 跳步后可合理推导，也可复述已给出的规则，但不能把复述直接记为深层理解。课前探测若答对，要审查推导；不因出现目标公式就自动判泄漏。
- **未教知识泄漏需证据。** 区分已有知识推导、教师刚提供的结论与无依据调用。只看口头答案无法判断时标“待复核”，结合画像、初始前置提取、教师来源和知识状态确认。
- **来源要看语义。** `p…`、`t…` 等以当次实际日志为准，不预设编号。某教师来源若只有提问而没有陈述答案，不能单凭其 ID 存在就判来源正确。学生自主推导不应被描述成“老师已经讲过”。
- **纠正要看后续使用。** 学生说“明白了”不算恢复；需要新题和理由支持。明确撤回的错误规则不能继续支配后续回答。若状态可见，还应检查相关冲突或疑问是否随证据合理更新；不要求匹配某个固定内部字段或精确措辞。
- 逐轮分别填写“通过 / 失败 / 待复核”，不预填实际结果。B 发现真实缺口是有价值的观察；若学生如实表达缺口，其知识边界表现可以通过，并不表示其已掌握该知识。
- 路径结论须附证据：所有必测提问轮均已审核且无失败、无待复核，才记该路径通过；有失败则失败；没有失败但有待复核则待复核。纯讲授轮不要求发言。

## 5. 记录和复测

将各稿末尾的空表复制到测试者自己的记录文件中填写，保留原始测试稿不变。一次运行包括以下信息：

| 字段 | 实际记录 |
| --- | --- |
| 日期、测试者、案例编号、重复次数 | |
| 项目版本/提交号、模型名称及可见配置 | |
| 主题、年级、学科、水平、课型、教材版本 | |
| 实际确认画像及初始前置提取的证据位置 | |
| 输入方式、审核开关、静音/播报设置 | |
| A 会话编号、B→C 会话编号 | |
| 各路径实际起止时间 | |
| 日志/导出文件路径、关键事件定位 | |
| 偏离脚本、识别错误、失败重试或链路异常 | |

同一配置可重复执行完整案例，重复之间创建新课堂；初次建议每课完整执行一次，出现失败或待复核后再按相同输入复现。只报告实际完成次数，不将单次结果解释为稳定通过率。语音识别改变了题意时，将该次标为输入链路异常，保留证据后用文字另起课堂复测，两个结果分别报告。

## 6. 本套材料的交付边界

已提供脚本与人工判定依据，没有音频、自动测试程序、模型调用或真实测试结论。全部演示实验用文字给出观察事实，不要求进行化学或电学实物实验。末尾的“判定区”仅供测试者查阅，不发送给学生。
