## 执行器和测量口径

执行器：[tests/live_classroom_acceptance.py](../../../tests/live_classroom_acceptance.py)。默认两个隔离课堂任务并行，使用真实 `Session` 和 `ReportService`，在独立数据目录运行；当前代码中的结算服务仍按自身锁顺序生成报告。不会连接、停止或重启用户正在使用的服务，也不写用户本机模型设置。

- 画像取各科原材料的固定画像，不额外生成新画像；B 与 C 必须同一课堂连续执行，A 独立。
- 文字逐轮输入，静音关闭，ASR 和 TTS 关闭。手动 flush 排除自动文本分段等待，发言仍经过生产时钟和真实静默时间，不传入虚构静默值强制放行。
- `processing_seconds`：教师输入到状态生成；`reply_seconds`：教师输入到实际 reply 事件；`seconds`：本轮处理与复核稳定后总等待。纯讲授轮沉默允许，明确提问未实际发言记为异常。
- 所有模型输出保留阶段、尝试次数、耗时、用量；逐轮保留教师文本、学生原话、候选发言、知识状态与来源编号。语义结论需根据原材料判定区逐轮复核，不能把技术完成状态当成教学通过。
- 记录结构修复、关联校验、截断、学生恢复、知识复核失败。学生本轮失败最多显式重试一次；结算首次失败后最多显式重试一次，并分别保留首次状态和最终状态。恢复成功不能抹去第一次失败。
- 记录结算总耗时（含本测试服务的报告排队等待），检查真实分段路径、结算前未处理来源和未复核知识，并在报告成功后验证再次 start 不额外请求、新服务实例读取结果一致。
- 整批最多 450 次模型请求尝试，包括内部修复和显式重试；未要求耗尽预算。初始化连接失败或认证/额度错误后停止后续课堂，避免对持续故障反复发起请求。此停止策略是在本次阻塞后加入，原始 13 次失败记录不被覆盖。
- 当前执行器支持 `--select` 选择课堂；没有 `--live` 时仅做静态预检，不调用模型。

## 底层连接原因确认

用户反馈 LFY 可以正常使用后，对测试进程原有网络路径作无密钥诊断，未更改网络、代理或权限配置。该进程的 HTTP_PROXY/HTTPS_PROXY 及小写变量均指向 `http://127.0.0.1:7890`。HTTPX 的实际连接目标是这个本机代理端口，底层异常链为：`httpx.ConnectError → httpcore.ConnectError → OSError → PermissionError: [Errno 1] Operation not permitted`。

因此已定位本次测试进程的直接阻塞点：连接本机代理被执行环境权限拒绝，尚未得到模型 HTTP 响应。先前的 DNS 失败是附加诊断现象，不能当作实际代理请求的唯一失败原因。用户普通应用能使用 LFY 与受限测试进程无法连接代理并不矛盾；没有证据支持课堂占用导致失败。

本诊断只对服务根路径作无密钥 GET，没有发起新的付费模型生成。需要由宿主执行环境允许相应网络访问后，才能在当前代理配置下实际运行这套回归；本会话没有可用的权限提升入口，不尝试通过其他应用绕开限制。
