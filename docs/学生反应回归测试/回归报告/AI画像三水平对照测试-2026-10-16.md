# AI 画像三水平对照测试

测试日期：2026-10-16（北京时间）。

## 结论

**部分符合预期，但目前不能认为三个水平能稳定生成合格的差异化画像。** 模型会改变支持需求、困难描述和已有知识，但出现普通水平比扎实水平知道更多本课答案、薄弱学生被预设掌握待讲知识、未知栏目直接透露结论等问题。结构校验通过不代表教学设定正确。

本轮直接使用产品的画像生成服务和课前知识提取服务，调用真实 DeepSeek 模型。没有修改产品代码，没有运行课堂对话；关于课堂行为的影响仅说明已进入初始知识的风险，不声称已经观察到具体学生回答。

## 测试设置和预期

取现有五份回归材料中的主题、年级、学科、待讲知识点，固定为新课、教材留空，每课只改变 `student_level`，各生成一次。共 5 题材 × 3 水平＝15 份画像，再为每份画像调用实际课前提取器。

材料里还建议“只填主题，让模型推断其他字段”。本轮为了只比较水平，采用材料中的明确教学设置，未覆盖仅填主题时的年级、学科和知识点推断。

预期不是三个水平掌握完全不同的课程：薄弱学生应保留合理基础，将具体不稳固的前置列为困难；普通学生应有常规基础，在新情境中需要示例；扎实学生应稳定掌握必要前置，能在已知范围内迁移。**三个水平都不能把明确的本课待讲内容直接作为已掌握知识。** 不以字数或知识条数直接判断水平高低。

测试版本为当前 `fix：对学生画像分析已知问题修复` 分支及工作区已有的 `backend/prompts.py` 修改；提交及 Prompt SHA-256 见原始汇总，测试前后 Prompt 哈希一致。结论属于这一版本，不代表主干版本结果。

## 五个题材的实际差别

| 题材 | 基础薄弱 | 普通 | 基础扎实 | 判断 |
| --- | --- | --- | --- | --- |
| 一元一次方程 | 写成“熟练”有理数运算、会简单方程，且已知完整等式性质；需要逐步演示 | 已知常规运算和逆运算，等式性质正式表述仍属未学 | 同样已知完整等式性质、简单方程；困难仍集中在移项变号和步骤混乱 | 梯度不稳定，薄弱与扎实都提前获得本课等式性质，薄弱基础强于预期 |
| 一次函数 | 已学正比例函数定义、图像和增减性；依赖数表、图像和提示 | 常规前置较完整，需要完整示例 | 增加反求自变量、平移等基础，但也直接把一次函数定义列为已知 | 支持方式有区别；扎实档通过提前学习本课定义形成差异，不合格 |
| 密度 | 质量、体积、测量和比值基础；比值物理意义需分步引导 | 已知密度定义、公式、单位换算、同种物质性质，甚至公式变形 | 已知测量、除法和比例基础，但仍未学密度定义、公式和单位 | 明显倒挂：普通比扎实多知道整组本课目标，且普通画像内部矛盾 |

| 质量守恒定律 | 质量、变化、天平基础；多步和气体问题易混乱 | 增加质量单位换算等基础，称量范围仍需引导 | 增加化学式、反应实例、物理变化质量不变等已知 | 有部分合理差异，但增强偏向化学事实扩展，称量收支推理能力梯度较弱 |

## 关键证据和影响

### 1. 待讲内容进入“已有知识”，实际被初始化

`01-weak` 已有知识原文：

> 学生知道等式两边同时加上或减去同一个数，等式仍成立；等式两边同时乘或除以同一个不为零的数，等式仍成立。

本课明确待讲“等式性质、移项的依据、解方程与代入检验”。提取器将上述整句纳入 `initial_prerequisites`。`01-strong` 也出现同一句。教师原本想观察省略等式性质是否造成障碍，这样的画像会预先满足该条件。

`02-strong` 已有知识原文：

> 学生掌握一次函数 y=kx+b 中 k、b 为常数且 k≠0 的形式定义，知道当 b=0 时它退化为正比例函数。

它也进入初始知识。但“一次函数的表达形式”正是本次新课目标，不能仅因基础扎实就预设掌握。

`03-normal` 已有知识原文：

> 学生知道密度的定义是某种物质组成的物体的质量与它的体积之比，密度公式为ρ = m/V，其中ρ表示密度，m表示质量，V表示体积。

同一画像还写入 `1 g/cm³ = 1000 kg/m³`、公式变形和同种物质密度不变，并均被实际提取。其知识边界又称“尚未系统学习如何用质量与体积的比值来定义密度”，构成直接冲突。扎实档却仍不知道这些本课内容，说明本次差异不能解释为健康的水平递进。

### 2. “不知道／困难”栏目仍然夹带答案

代表性原文：

- `02-weak`：可能对“k 的符号决定增减性”这一结论的适用范围和前提条件理解不清。
- `03-weak`：学生尚未学习密度单位的换算关系（如1 g/cm³=1000 kg/m³）。
- `04-strong`：可能将“电阻一定时，电流与电压成正比”和“电压一定时，电流与电阻成反比”两个结论的变量条件混淆。
- `05-normal`：学生不知道如何用原子种类、数目不变来解释反应前后质量相等。
- `05-strong`：不能直接说出化学反应前后总质量不变这一规律。

上述文字并没有因为前面加上“不知道”就消除事实信息。它们违反当前 Prompt 的答案隔离要求。**本轮没有追加学生追问，不能将上下文夹带直接统计为课堂回答泄漏率。**

### 3. 关键前置缺失，或写在了不会被初始化的位置

欧姆定律扎实档在“理解基础”写：

> 学生能进行简单的代数运算，能理解正比例关系、反比例关系的数学含义，并能从表格或图像中初步判断两个量之间可能存在的比例关系。

实际提取结果只有 7 条电学与控制变量知识，没有这条数学基础。薄弱档也未明确列出正反比例定义；普通档只写“能识别……基本特征”，没有明确比例关系的数学含义。不能据此宣称关键数学前置已稳定覆盖。

质量守恒普通档的“理解基础”中写了“总质量”是各物质质量之和，但没有出现在实际初始知识里；扎实档则把这一内容正确写进已有知识并被提取。说明知识分类仍会改变实际初始认知。

### 4. 薄弱和扎实的认知差别不够具体

薄弱画像保留低学段基础是合理的，但方程薄弱档同时写“熟练”负数四则运算、合并同类项、解简单方程和完整等式性质，困难又主要落在本课新内容，未充分体现哪些前置操作不稳定。

扎实档在密度、欧姆定律和质量守恒中仍多次使用“需要示例支持”“需要教师提示”，这些描述对新知识本身并非错误；问题在于没有同时清楚展示它在**既有基础**上的独立推理和迁移优势。不能只增加知识条目就认为差异化达标。

## 完成情况和限制

- 15/15 份画像生成成功，15/15 份课前提取成功；教师指定的年级、学科、知识点均完整保留。
- 真实 API 共 32 次请求：画像 17 次（含 2 次结构自动修复），课前提取 15 次。两次修复分别移除多余的 `student_profile_note` 和 `textbook` 输出字段。
- API 返回用量：输入 38138、输出 17077，合计 55215 tokens。
- 画像相关本地自动测试：12 passed。存在现有 Starlette/httpx 弃用警告。
- 初次在受限网络下的 15 次尝试均未收到模型输出；随后联网运行成功。原始事件文件保留了两段记录，成功运行的请求数与用量以上述汇总为准，不能把前面的失败尝试算作生成样本。
- 每个“题材×水平”仅抽样一次，两个结构修复样本经历了额外生成，不能据此计算稳定发生频率或把所有差异严格归因于水平。已足以证明存在不符合预期的反例。
- 本轮没有覆盖浏览器点击、语音、完整课堂反应或主干对照，也没有修改 Prompt。

## 建议的修正顺序

1. 优先将明确待讲内容从已有知识中排除，检查四个栏目是否夹带本课结论。
2. 建立同一题材共享的必要前置清单，再针对具体前置标注稳定、需提示、不稳固，避免三档各自重新猜测整套知识。
3. 将用于推理的数学和学科前置放入已有知识；理解基础只描述支持方式，并核对实际提取结果。
4. 修正后以相同设置重复抽样，再追加课前边界和跳步教学追问，验证画像变化是否真正改变课堂表现。
