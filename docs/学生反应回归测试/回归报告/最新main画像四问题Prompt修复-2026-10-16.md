# 最新 main 上的学生画像四问题 Prompt 修复

日期：2026-10-16，北京时间。分支：`fix：对学生画像分析已知问题修复`。

基于 `7597b49` 开展，其父提交为最新 main 合并节点 `b1c851b`，包含五状态认知、依赖复核、静音恢复和教师回应请求机制。本报告对应本轮重新实现，先前被放弃的修复代码没有恢复到产品中。

**结果：四项问题已完成针对性修复与真实抽样验证。产品改动仅限 `backend/prompts.py` 中的画像生成、前置提取和学生回复三个 Prompt；没有增加线上 API 阶段、确定性内容过滤或改变状态机。不是所有题材、所有随机生成的稳定性保证。**

## 四项问题及验证依据

| 问题 | 本轮修复 | 实际观察 |
| --- | --- | --- |
| 自动年级别名回填成自定义 | 明确界面标准值及常用别名；仅自动推断采用标准值，显式年级仍保留 | 自动生成“20以内的加减法”返回“一年级”；导数主题返回“高二”。真实 Chrome 点击生成并复用这两份原始 API 响应，回填标准选项；一年级选项属于“小学”组。既有自定义、覆盖保护、失败保留及教师已填字段测试通过。 |
| 一年级按中学基础生成 | 小学一二年级分支优先于主题与水平；前置限定为低龄计数、加减、形状、分类与可见观察；超纲需确认补先修 | 修改前一次函数样本含有理数、字母与坐标系，欧姆样本含电学定义、串并联和仪表；修改后两份一年级样本仅保留低龄基础，并明确主题超出学段。原始结果也通过浏览器回填。 |
| 三水平梯度失真、目标泄漏、前置遗漏 | 五题材使用明确的合法前置池；四段均不得讲目标答案。薄弱档记录复杂前置操作缺口；普通档常规操作独立、新联系需示例；扎实档追加两项具体独立前置任务。PREPARE 要完整摘录所有已确认前置 | 方程画像不再预设等式变形与解/检验；密度不再预设物理比值关系；化学不再预设守恒结论。欧姆同题薄弱/普通/扎实对照成立，扎实档两项独立任务实际进入初始知识；数学正比“比值一定”、反比“乘积一定”明确保留。函数强档追加两项正比例函数独立任务且完成提取。 |
| 三课型差异不可靠、预设掌握 | 新课侧重旧知比较与建立联系；复习侧重回忆、条件辨析和纠错；应用侧重多条件、情境数量对应、整合与检查。后两者明确目标掌握待确认 | 同一欧姆主题、同一普通水平的新课/复习/应用三份输出，保留相同合法旧知，任务与目标边界不同；未因课型认定已经掌握目标，也未把复习课写成从未学过。 |

## 课堂联动与额外修复

只做了一次欧姆定律课前探测及一次失败点复测，没有重放五科长课堂。均通过真实 `Session`，文字输入、非静音、关闭 TTS 和 ASR 审核；检查实际送达回复。

首测学生准确回答数学正反比例并承认不知道电学关系，却随后以“如果硬猜”补出无来源的电学关系。六条初始知识中没有该关系，知识状态也未新增该关系；仍将此候选回复判为来源边界失败，没有算作通过。

只在学生 Prompt 补充：不得借“猜测/可能”输出无来源的领域公式或规律；允许从有效前置及已讲内容进行有依据的推导。复测直接复用同画像、同 PREPARE 规则已提取的六条前置，省去重复生成与提取，只调用一次模型。实际送达：

> 数学上正比例是两个量比值一定，反比例是两个量乘积一定，这个我学过。电压6伏、电阻3欧时怎么确定电流，我还没学过本课的关系式，不知道；我只能说电流的单位是安培，但具体数值不能靠猜。

这仅验证当前状态机中的一次真实课前边界，不表示完整教学路径或语音输入已经验收。

## 用量及测试范围

全部批次合计 **80 次请求尝试，74 次有效模型响应，136,852 tokens**。其中6次尝试在最初受本地网络权限阻止，无模型响应、无返回用量。其余响应包括修改前基线、未通过的 Prompt 候选、结构修复与最终针对性复测。输入117,043、输出19,809；输入缓存命中63,232、未命中53,811。实际金额以服务商账单为准。

用户提醒费用后取消全组合矩阵，将共享请求硬上限从160降至80；达到上限后已停止。没有通过换账本追加调用。测试只用合成教学数据和项目现有配置，不发送教师真实课堂资料。

没有跑45组或90组全矩阵，没有将中间版本拼成“最终版本全量通过”。证据分层如下：

- 边界原句池版本：方程、密度、化学、两份小学一年级，共5份适用证据；当时函数强档缺独立任务，已排除其通过依据。
- 最终画像生成 Prompt：补充强档专用任务和电流措辞后，验证函数强档及欧姆5种配置，共6份、40条前置，均完整提取；另两份自动年级仅生成画像，不进行无关提取。
- 最终学生 Prompt：画像生成与 PREPARE 内容未变化；复用已提取结果，只复测前述无来源猜测问题。

前两层共11份适用画像的71条前置全部逐字进入实际提取结果；这些是分阶段证据，不能描述成同一最终版本的11份完整重测。小学普通档样本的先修缺口中仍有“多步四则/代入”措辞，其上下文是待补先修，未进入已有知识；不据此认定学生会中学代数。函数强档“描点作图处理不稳固”只在待学一般一次函数任务中出现，正比例函数旧知与独立作图任务已明确保留；教师确认时仍需关注任务范围措辞。

离线自动检查只验证字段保留、分段、提取覆盖及筛查候选，不替代内容复核。薄弱档的“运算顺序核对需支持”与“符号处理不稳固”是两项具体旧操作缺口；不会因其中只有一项字面写了“不稳固”就忽略第二项，但保留自动筛查标记。
