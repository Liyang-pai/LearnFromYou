# 删除题材知识池后的泛化观察

日期：2026-10-17，北京时间。

> **重点结论：本轮语义验收未通过。**
>
> **已确认不符合预期：扎实档能力落位与提取不一致、应用课擅自预设学习经历、方程目标提示泄漏、薄弱档缺少具体旧操作差异。**
>
> **另有两项风险需复核：二分查找端点更新描述可能误导，小学场景的先修预设与水平支持方式仍需确认。** 能生成新题材内容、9份结构有效和23项离线测试通过，均不能替代这些内容问题的验收。

**已删除产品画像 Prompt 的全部题材专用前置知识池、固定低龄知识清单、扎实档专用任务句及矩阵专用示例。改用通用依赖判断、学段优先、水平和课型区分规则，保留知识点自动拆分。真实测试表明能生成新题材内容，但尚不符合完整语义验收预期。**

没有为了测试结果再把题材补丁加回产品，也没有修改学生状态机或增加线上 API 阶段。已有提交 `98f0826` 保留；本轮变更未提交或推送。

## 改动边界

产品变动仅在 `STUDENT_PROFILE`：根据每个目标向前分析必要的概念、运算、操作及跨领域依赖；排除目标本身、其特例及等价改写；依据实际学段与水平判断已知和先修缺口。不在产品提示词中提供具体课程的“标准前置答案”。

界面的年级和学科标准选项保留，它们属于回填接口约束。三水平与三课型保留通用行为要求，不再逐题指定应该会什么。试题及明确的失败例仅存在于测试程序、证据与报告中。

## 小规模真实测试

一次生成9份画像，全部使用当前同一 Prompt，不做全组合矩阵：

- 新题材“二分查找”：固定相同年级、学科、知识点，比较薄弱/普通/扎实三水平，以及普通档新课/复习/应用三课型，共5份。
- 新题材“记叙文中的人物描写”“光合作用”：只给主题，共2份，观察自动知识点拆分与学段推断。
- 旧失败点：七年级薄弱档方程课、小学一年级欧姆定律，共2份。

再复用二分查找扎实档画像，只调用1次前置提取，没有重新生成画像。全部9份画像结构有效；**结构有效不是内容通过，本轮未给出“9/9通过”的结论。**

## 观察结果

### 能泛化生成，但不证明正确稳定

计算机、语文、生物题材均生成了相关前置与目标，没有只能识别原五题材的限制。人物描写拆成6个目标，光合作用拆成5个；本轮自动推断返回标准年级值，显式输入也被保留。

### 重点：不符合预期的证据（未通过项）

| 判定 | 项目 | 预期要求 | 原始证据与判断 |
| --- | --- | --- | --- |
| **不符合预期** | **扎实档能力落位与提取不一致** | 两项独立前置任务明确列在已有知识段，后续按该段完整提取。 | 二分查找扎实档的两项独立任务**写在“理解基础”**。实际提取没有漏掉8条已有知识，却又从理解基础**额外提取了1个含独立任务的能力片段**。不能说任务完全丢失，但段落分工和实际初始化不一致。 |
| **不符合预期** | **应用课仍预设既往经历** | 未提供学习记录时，仅说明目标掌握待确认，不断言以前学过或没学过。 | 同一份输出的理解基础写“目标掌握与迁移能力尚待确认”，边界却写**“以上内容均未在本课前系统学习”**。用户未提供学习记录，这一断言没有依据。 |
| **不符合预期** | **方程目标提示重新混入困难** | 待教目标的操作、依据和结论不能通过任何画像栏目提前提供给学生。 | 出现**“等式性质中‘两边同时进行相同运算’”及移项符号变化提示**。目标没有写入已有知识段，仍会通过困难描述进入学生上下文，**未满足目标隔离要求**。 |
| **不符合预期** | **薄弱档差异仍容易落在新目标** | 至少明确两项已有前置操作的具体困难，以体现弱档基础，而不是仅列本课新目标。 | 二分查找的困难主要围绕本课边界、更新与终止，**没有稳定形成两项旧操作的具体缺口**。不能仅凭“分步提示”字样判定梯度合格。 |
| **语义风险，需复核** | **新题材的内容准确性** | 不把合法操作描述成错误，不通过困难描述暗示错误方法。 | 二分查找弱档、普通档把**“只更新/只移动一个端点”描述成问题**，可能误导为每轮都必须同步移动两个端点；**标准二分每轮通常只更新一个端点**。此项按语义风险记录，而非结构错误。 |
| **先修预设待确认；支持方式偏弱** | **小学场景仍需确认** | 已知能力须符合实际学段；普通档的常规前置操作应可独立完成，不能未经确认预设具体学习经历。 | 正确保留小学一年级及主题超纲提醒，未直接给中学电学公式；但**预设会连简单电路，教师输入没有确认该经历，普通档支持方式也偏弱**。仅凭出现“电路”一词不能证明越级，所以保留先修待确认，不按关键词武断判错。 |

**以上按问题类别列项，不代表6份独立失败样本；同一份画像可能同时涉及多项问题。本轮没有据此统计画像通过率。**

自动筛查也发现强档任务位置、应用课确认边界与小学普通档支持方式问题；同时修复了离线审查器将“理解基础运算律”误识别为“理解基础”段标题的解析问题。关键词只用于定位人工复核，不替代语义判断。

## 验证与用量

- 相关离线测试：23 passed；既有 Starlette/httpx 弃用警告保留。
- 一份真实前置提取完成，暴露额外跨段提取问题，没有将其计为语义通过。
- 未执行课堂、语音或浏览器全量回归。本轮不能推导课堂整体通过。
- `git diff --check` 通过；产品 Prompt 已无固定知识池与题材专用任务。

本轮合计 **10次 API 请求、10次响应、20,343 tokens**：输入16,190，输出4,153；输入缓存命中10,880、未命中5,310。预算硬上限12次，剩余2次未使用，调用已停止。没有重复生成已抽取的画像，没有在观察到失败后启动大规模重跑。

结论是：去掉知识池后具备跨题材生成能力，但先前题材上的改善不能视为通用稳定性。当前语义问题主要涉及目标隔离、水平能力落位、课型经历边界与事实准确性，不能靠结构校验通过来掩盖。
