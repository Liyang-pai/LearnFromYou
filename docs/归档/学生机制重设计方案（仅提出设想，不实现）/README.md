## 核心设计取舍

- 取消逐条知识五状态和完整依赖图作为运行中心，改用简短、可修订的话题理解笔记。
- 保留完整课堂原文、图片绑定、纠正、历史及实际送达记录；模型每轮只读取当前任务需要的材料。
- 学生可以根据讲解形成新的理解，并在已有基础允许时合理推导。掌握与迁移的报告结论需要对应的实际任务证据。
- 教师的错误讲授可能形成学生的错误理解；课后教学评价的答案不回灌给学生。
- 纠错先采用按话题保守重建，接受局部更新较粗的代价。跨话题更正漏关联与模型借用未教知识，是后续必须验证的问题。
- 保留必要的小型事务状态机，编号、输入版本、提问次数等由程序维护。候选、取消与实际送达分别记录。
