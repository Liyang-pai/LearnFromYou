# 讲给我听 · 独立静态交互原型

日期：2026-10-17（Asia/Shanghai）。基于已交付的42张小纸原图版设计，供本地体验和队友讨论。

**当前为大字圆体版，含Mac与Windows入口。** 发给队友请使用“讲给我听-大字圆体版-Mac与Windows.zip”。正文、按钮和说明文字加大，字体随包离线加载，减少边框、渐变和装饰。原有交互修复保留。先看[42页PNG图册](output/visual-refresh/index.html)或[六页总览](output/visual-refresh/六页总览.png)，简要交接见[给队友的说明](给队友的说明.md)。

## 打开

先完整解压压缩包，保留所有文件夹：

- **Mac推荐：** 在Finder中右键 `index.html` →“打开方式”→ Google Chrome，也可将文件拖入Chrome窗口。
- **Mac快捷入口：** 双击 `打开静态原型-Mac.command`，由默认浏览器打开。若系统阻止脚本或解压工具丢失执行权限，直接按上面的方法打开HTML即可。
- **Windows：** 双击 `打开静态原型.cmd`，或用Chrome/Edge打开 `index.html`。

不需要安装依赖、启动服务器、填写密钥或下载模型。已验证Windows Edge和Unix shell入口的路径处理；尚未在真实macOS机器或Safari实测。

文件集中在本目录，与产品Git仓库、原调试前端、后端端口、`.env`、模型和课堂日志隔离。刷新或“重置演示”会清空当前模拟内容；不会读写真实课堂。

## 建议先体验这条流程

1. 首页点“创建一次试讲”，填写主题，生成模拟画像；也可以手写、编辑画像或调整教学设置。
2. 确认创建后进入“我的教室”。点麦克风仅切换模拟收音；本原型不申请麦克风权限、不录音、不播报。
3. 输入一段讲解，或用上方“演示下一步”，体验听课、思考和固定文案回应。这里没有真实AI推理。
4. 上传或粘贴本地教学截图，先预览、再确认；取消时保留当前图。图片使用浏览器内的临时对象URL，不发送到任何服务。
5. 用“课堂偏好”分别控制学生发言、中央字幕和播报设定；查看转写、认知、模型结果与处理记录的示意。
6. 结束试讲，查看模拟教学报告；可实际下载带“模拟”标记的Markdown报告、JSON课堂记录和识别测试结果。
7. 在设置中体验编辑、保存和未保存提醒；连接、模型下载、校验与识别都由本地固定数据和定时器模拟。
8. 用上方“异常演示”体验画像失败、课堂失败、报告失败、截图失败、权限受限与连接中断；“场景”菜单可以直接查看全部42个页面和状态。

## 关键边界

- 不调用fetch、WebSocket、模型API、音频设备、系统语音或产品服务；CSP进一步禁止网络连接和媒体加载。
- 模拟模型下载不会下载文件，模拟保存不会修改 `.env` 或外部账户。请勿填写真实密钥；密钥输入不会保存或导出。
- 固定样例不是专业教学判断，也不代表模型效果、语音识别质量或真实连接状态。
- 只有用户选择的图片在当前内存里预览；导出文件由浏览器另存。原图文件不会被修改。
- 原调试前端没有被修改；原型中的两张调试画面只提供静态示意，不连接真实调试服务，上传录音不工作。
- 桌面画面按1600×1000缩放适配浏览器窗口，适合桌面/笔记本审阅；不是已经完成的手机正式产品。
- 未提交、推送或修改PR #17。本次原型仅本地交付，后续是否共享由用户决定。

## 文件

- `index.html`、`打开静态原型.cmd`：用户入口。
- `src/screens.js`：原42张设计的本地模板。
- `src/app.js`、`src/interactions.js`、`src/features.js`：导航、表单与模拟行为。
- `src/prototype.css`：外层评审工具栏和画幅缩放。
- `src/theme.css`：统一的大字圆体与浅蓝简洁样式；字体在 `assets/fonts/`，无需安装或联网。
- `assets/`：用户提供的小纸透明原图。
- `tools/prepare.cjs`：从已有设计包提取模板；只有重新整理模板时才需要。
- `tools/smoke.cjs`、`tools/acceptance.cjs`：离线浏览器检查；验证结果和截图在 `output/`。
- `tools/repair-regression.cjs`、`tools/link-audit.cjs`：本轮修复专项及全场景即时点击检查，结果在 `output/`。
- `tools/package.py`：生成共享ZIP，逐文件核对压缩包内容，并解压到独立临时目录供复查。
- `tools/visual-check.cjs`、`tools/visual-gallery.cjs`：42场景字体、排版、主要操作可见性检查和PNG图册生成。

自动检查使用已提供的Playwright环境，浏览器通过 `DESIGN_BROWSER_PATH` 选择。查看原型本身无需Node或Playwright。

验证范围以 `output/acceptance.json` 为准：仅静态原型的实际点击、内存状态、导出、场景可达性与网络隔离，不替代产品功能或模型验收。

本轮另检查42场景的640个可见启用候选入口，通用占位提示0、脚本错误0；专项验证了已发现问题的实际鼠标点击、键盘关闭、下载及模拟状态变化。完整范围见[链接检查说明](output/链接检查说明.md)。来源/许可弹窗显示产品清单中的地址，供选择复制；原型不自动访问外站。

大字版已重新通过15组主流程、9组交互修复专项和42场景视觉检查；字体加载、图片加载、主操作无遮挡和横向排版通过，未发现外部请求或脚本错误。说明与字体来源见[视觉调整说明](视觉调整说明.md)。PNG为首屏快照，完整内容请在原型中滚动查看。
