# 讲给我听 · 静态原型交接

这是可点击的独立静态原型，用来评审页面、流程和视觉效果。沿用42个场景与用户提供的小纸素材。

**最新包：讲给我听-大字圆体版-Mac与Windows.zip。** 字体已内置，换成圆润字形并放大正文、按钮和说明，卡片采用奶白浅蓝与轻边框。`output/visual-refresh/index.html` 是42张首屏PNG图册，`六页总览.png` 便于快速看风格；完整页面内容在原型中滚动查看。

## 怎么看

1. 完整解压压缩包。**Mac用Chrome打开 `index.html`**（Finder右键→打开方式→Google Chrome，或把文件拖进Chrome窗口）。可选双击“打开静态原型-Mac.command”；Windows用“打开静态原型.cmd”。不要只发送单个HTML，需保留同目录的 `src/` 和 `assets/`。
2. 首页创建试讲，填写主题并生成模拟学生画像，确认后进入“我的教室”。
3. 输入讲解，体验固定文案回复；选择本地截图，预览后确认；结束试讲后查看并下载模拟报告。
4. 顶部“场景”菜单可查看全部42个页面状态，“异常演示”可体验失败和恢复。设置、调试入口也可点击。

不需要安装、启动服务、配置密钥或下载模型。刷新会清空当前模拟数据。

Mac若阻止 `.command` 或解压后没有执行权限，直接打开 `index.html` 即可，无需修改系统安全设置。当前浏览器实测环境为Windows Edge，尚未在macOS或Safari实测。

## 本轮修了什么

- 调试课堂与ASR模型页签正确互跳；课堂内四个详情页签可切换。
- 调试麦克风、学生静音、语音播报开关有模拟状态；截图确认入口可选择本地图片。
- “全部事件”可筛选，“诊断导出”可下载模拟课堂记录，规则指纹可展开。
- 模型详情对应所选模型；可查看产品清单中的来源、许可地址与版本；校验、VAD准备和重新下载有模拟过程。
- 关闭弹窗支持鼠标和键盘；修复后重新检查42场景、640个候选入口，并通过主流程与专项回归。

## 接入正式产品时

本包没有连接后端、语音设备或真实模型。真实API、WebSocket、录音、语音播报和文件管理需要由正式实现接入；当前的连接通过、模型下载、识别和教学评价均为模拟结果。

导航统一为“我的教室”。正式前端除上传录音及内部来源/依赖关联（如t1）外，需保留原调试前端其余功能和信息；原调试前端继续保留。小纸图片是独立素材，后续可替换成交互动画。

原产品仓库与设计PR #17没有被本次原型修改。设计PR：https://github.com/Liyang-pai/LearnFromYou/pull/17 。本包供本地评审，不代表正式功能已经接入。

验证记录位于 `output/`；发现问题请记录操作路径、场景编号和预期效果，方便对应到页面。
