# 大字圆体版 · 2026-10-17

按用户“字体大一点、可爱一点、整体简洁一点”的要求，修改现有静态原型的统一样式。

- 正文15→18px，输入框主要文字12/13→17px，常规按钮13→16px，主导航15→18px，页标题32→38px；说明文字主要为14–16px。
- 内置寒蝉全圆体，离线加载，Mac和Windows不用安装字体。技术JSON区域仍使用等宽字形，便于阅读。
- 使用奶白、浅蓝和少量薄荷色，卡片弱化边框与阴影，减少渐变、英文副标和装饰说明；保留小纸原图。
- 长内容可滚动，创建区域主要按钮保持可见；设置内容与保存区独立排列，连接测试按钮不会被保存栏遮挡。
- 使用独立 `src/theme.css` 覆盖样式，没有改动产品仓库、后端、模型或原型路由处理逻辑。
